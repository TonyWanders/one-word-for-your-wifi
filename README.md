## What it does

`main.py` (Python 3, standard library only) writes exactly one word to `/output/entry.txt` and to stdout: **Limbo**. No trailing newline, no extra words. It is deterministic and uses no network.

## Why this word

Wi-Fi lives in limbo: not quite connected, not quite gone, the page half loaded forever. And like the dance, the only question it ever asks is how low can you go, one signal bar at a time.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is 5 characters, one word only.
